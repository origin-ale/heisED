# Heisenberg Exact Diagonalization
This is a small project for the Interactions and Correlations in Condensed Matter course at the University of Bologna. The aim is to find the ground state energy for the 1D spin-1/2 Heisenberg model using exact diagonalization supplemented by the Lanczos algorithm.

References: 
- A. W. Sandvik, AIP Conf. Proc. 1297, 135 (2010)
- J. M. Thijssen (2007). *Computational physics*, 2nd ed. Cambridge University Press.
- K. R. de Ruiter (2018) *Study of the ground state of the one-dimensional Heisenberg spin-1/2 chain* . Bachelor thesis, Utrecht University. Advisor: D. Schuricht.
